# C.O.S.M.O documents

- `Cosmo-Handbook.pdf` is the full handbook.
- `Cosmo-Brochure.pdf` is the brochure.

Rebuilt from the source in Ray's cosmoai repo. When they change, the files here are replaced.

## Preview in the browser

`html/` has the same documents as web pages (open `html/index.html`), so either can be previewed from a link once the site is published. They carry a "noindex" tag so search engines skip them, and nothing on the website links to them.
